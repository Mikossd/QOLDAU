# Qoldau Food (Қолдау Food) 🇰🇿

> **«Біліп жеңіз / Знайте, что вы едите / Know what you eat»**
> Веб-приложение для сканирования штрихкодов продуктов питания для потребителей Казахстана.

Qoldau Food позволяет сканировать штрихкод камерой смартфона или вводить его вручную, мгновенно получать проверенные данные из международной базы **Open Food Facts** и видеть простой, понятный анализ питательного профиля (сахар, соль, жиры, белки, аллергены) на трех языках: **Казахском (Қазақша)**, **Русском** и **Английском**.

---

## 🚀 Как запустить проект

### Способ 1. Запуск в 1 клик на Windows (ПК + Телефон)
Просто дважды кликните по файлу **`run.bat`** (или `start_mobile.bat`) в папке `qoldau-food`.  
Скрипт автоматически:
1. Запустит локальный веб-сервер на порту 8000.
2. Поднимет защищенный HTTPS-туннель Cloudflare для смартфонов.
3. Откроет страницу `http://localhost:8000` в браузере вашего компьютера.
4. В консоли выведет ссылки для компьютера и смартфона.

### Как открыть на смартфоне (iPhone / Android):
- На сайте на ПК нажмите кнопку **«📱 На телефон»** в верхнем правом углу.
- Наведите камеру телефона на сгенерированный **QR-код** на экране ПК.
- Сайт откроется по защищенному протоколу HTTPS — камера на телефоне запустится с аппаратным автофокусом и зумом.

### Остановка сервера:
Дважды кликните по **`stop.bat`** — скрипт корректно остановит все процессы и освободит порт 8000.

## 📱 Основные возможности (MVP)

1. **Сканер штрихкодов камерой (`html5-qrcode`)**:
   - Мгновенный запрос доступа к камере смартфона или ноутбука.
   - Поддержка стандартов: **EAN-13**, **EAN-8**, **UPC-A**, **UPC-E**, **Code 128**.
   - Переключение между основной (задней) и фронтальной камерами.
   - Сканирование штрихкода из файла фотографии при отсутствии веб-камеры.

2. **Ручной поиск по штрихкоду**:
   - Удобное поле ввода с цифровой клавиатурой.
   - Готовые кнопки-примеры для быстрого тестирования:
     - 🍫 **Шоколад Казахстанский (Рахат)** — `4870001010143` (Префикс GS1 487 Казахстан)
     - 🌰 **Nutella** — `3017620422003`
     - 🥤 **Coca-Cola** — `5449000000996`
     - 🥛 **Milka** — `7622210449283`
     - ❓ **Тест: нет в базе** — `9999999999999`

3. **Интеграция с Open Food Facts API**:
   - Автономная чистая функция `getProductByBarcode(barcode)`.
   - Запрос к `https://world.openfoodfacts.org/api/v2/product/{barcode}.json`.
   - Корректная обработка статусов: найден (200), не найден (404), ошибка сети/интернета.
   - Очищенный объект без избыточных сырых данных.

4. **Страница продукта**:
   - Название, бренд, фото продукта (или аккуратная заглушка).
   - Определение страны по префиксу GS1 (например, `487` = 🇰🇿 Казахстан).
   - Таблица пищевой ценности на 100 г: калории (ккал), белки, жиры, насыщенные жиры, углеводы, сахар, соль.
   - Скрытие отсутствующих полей (не отображает пустые значения).
   - Состав продукта и значки аллергенов.

5. **Раздел «Простыми словами» (Easy to understand)**:
   - Объективные текстовые карточки на основе рекомендаций ВОЗ / UK FSA:
     - «Высокое количество сахара» (> 22.5 г / 100 г)
     - «Низкое количество сахара» (≤ 5 г / 100 г)
     - «Высокое количество соли» (> 1.5 г / 100 г)
     - «Высокое содержание белка» (≥ 10 г / 100 г)
     - Предупреждения об аллергенах.
   - Никаких выдуманных данных — утверждения формируются строго при наличии соответствующих цифр.

6. **Оценка продукта**:
   - Нейтральные метки: *Низкий риск*, *Умеренный*, *Повышенный*, *Недостаточно данных*.
   - Четкий отказ от медицинской ответственности: информационная справка, не диагноз.

7. **Фокус на Казахстан**:
   - Мультиязычность: **Қазақша (kk)**, **Русский (ru)**, **English (en)**.
   - Валюта: KZT (₸) заложена в шапку для последующего отображения цен.
   - Предзагруженные популярные казахстанские товары (Рахат, Пиала Gold, Натуральный кумыс).
   - Форма добавления товаров: если товара нет в Open Food Facts, пользователь может внести его в свою локальную базу (`localStorage`) с отметкой «Пользовательские данные».

8. **История сканирований**:
   - Сохранение последних просмотренных товаров на главном экране.
   - Быстрый переход к ранее просканированным товарам.

## 🛠 Технический стек

- **HTML5** — семантическая разметка с поддержкой доступности (ARIA).
- **CSS3** — переменные CSS (Custom Properties), Flexbox, CSS Grid, адаптивный дизайн (Mobile-first, 320px–1200px+).
- **Vanilla JavaScript (ES6+)** — без сторонних тяжелых фреймворков (React не требуется для чистого MVP).
- **Html5-Qrcode (v2.3.8)** — легковесная библиотека для работы с мобильными камерами и штрихкодами.
- **Open Food Facts API v2** — REST API открытой мировой базы продуктов питания.
